# 321-audio-recorder

Для режима непрерывной записи я бы выбрал таймаут сторожевого таймера **8 мс**.
В п3.2.4 измеренный максимум итерации суперцикла составил 1796 мкс, поэтому
8 мс дают запас примерно в 4,45 раза. Один буфер из 512 отсчётов при 44 100 Гц
заполняется за 11,61 мс: выбранный таймаут меньше этого времени и позволяет
раньше обнаружить остановку суперцикла. Сам перезапуск и переподключение USB
тоже занимают время, поэтому таймаут не гарантирует сохранение записи при сбое.

Это предложение по измерению потока с читающим компьютером. Работа всех команд
при таймауте 8 мс не проверялась; при остановке чтения компьютером синхронная
передача USB может ждать дольше. Для других режимов нужен отдельный замер
худшей итерации и пересмотр таймаута.

В опыте п3.2.6 используется команда `wdt_enable 2000`: две секунды удобны,
чтобы увидеть перезапуск после `hang`. При запуске прошивка сама не включает
сторожевой таймер. После включения командой он обновляется в конце суперцикла,
после всех задач; обработчики прерываний его не обновляют.
